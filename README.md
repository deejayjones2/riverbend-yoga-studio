# Riverbend Yoga Studio — Sophia Touchstone 3

Four-page responsive HTML/CSS website. Open `index.html` or publish with GitHub Pages.

Files: index.html, services.html, about.html, events.html, styles.css, six supplied PNG assets, and the supplied guided welcome MP3.

The request form is an HTML-only demonstration and is not connected to a server. Do not enter sensitive information.

GitHub Pages: repository Settings → Pages → Deploy from a branch → main / root → Save. Copy the published URL into the Touchstone 3 document.
